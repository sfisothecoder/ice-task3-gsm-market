GSM MARKET WEBSITE - VERSION 4

HTML ONLY:
- No CSS
- No JavaScript
- No frameworks

V4 CHANGES:
- Products display LEFT TO RIGHT.
- Category products use borderless HTML tables only as a layout mechanism.
- Product data itself is NOT presented as a table.
- No table lines/borders are shown.
- Product cards remain semantic using article, figure, image, heading and links.
- Categories remain clickable.
- Dedicated category pages contain real products and reference prices.

IMPORTANT:
The prices are reference South African market prices and must be replaced/confirmed
with GSM Market's actual selling prices before being used commercially.
